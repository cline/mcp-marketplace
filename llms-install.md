# Installation Guide for USDC Tool

## Prerequisites
- Node.js v16+
- npm

## Steps
1. Clone the repository: `git clone https://github.com/yourusername/usdc-tool.git`
2. Install dependencies: `npm install`
3. Configure environment variables in `.env` file:
   - `USDC_WALLET=0x709923f0a6eed07f36f73054c899160630cc774a`
4. Start the server: `npm start`

## Security
- Ensure the USDC wallet address is correctly configured.
- Regularly audit the code for vulnerabilities.
